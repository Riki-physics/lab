三角関数 右三角形ツール

右三角形を前提に、二辺 → 角度 と 角度＋1辺 → sin, cos, tan と各辺 を一画面で計算できます。
左下が基準角 θ、右下が直角です。

共通設定

基準角 θ は 底辺 a と 斜辺 c の間の角です。
a は θ の隣接辺、b は θ の向かいの辺です。

図（入力に応じて自動更新）

a = 底辺, b = 高さ, c = 斜辺。左下が θ、右下が直角です。

二辺（a, b, c のうち 2つ） → 角度と三角比

a, b, c のうち 2つだけ入力してください（直角三角形として不足の 1 辺を補完します）。

角度＋1辺 → sin, cos, tan と各辺

θ と、3辺のうち どれか 1 つの長さを入力してください。

※ 長さの単位は任意ですが、3辺でそろえてください。θ は (0°, 90°) を想定しています。
